**Qid Game**, Ytsejam Game Studio’nun 3–12 yaş için geliştirdiği eğitim odaklı mobil oyundur. Oyun yüzeyi eğlence gibi görünür; arka planda odak hızı, stratejik düşünme ve akademik sinyalleri ölçen bir analiz katmanı (ürün dilinde **Mila v11.4**) çalışır.

- **Android (yayında):** Kotlin — [Google Play](https://play.google.com/store/apps/details?id=com.ytsejamgame.qidgame)
- **Apple:** Flutter ile hazırlanıyor
- Stüdyo: [`ytsejam.games`](https://ytsejam.games/#games)

Bu case study’de ürünün tamamını değil, **freelancer olarak üstlendiğim yüzeyi** anlatıyorum: oyun modülleri, analiz ekranları ve Drive tabanlı kayıt mimarisi.

### Ürün bağlamı

- Onlarca / bellek bulmacası / nesne avı / matematik baloncukları gibi pedagojik oyun modülleri
- Ebeveyn için şeffaf ilerleme ve performans görünümü
- Çocuk uygulaması gizlilik standardı: kişisel veri stüdyo sunucusunda tutulmuyor; ilerleme kullanıcının **kendi Google Drive** hesabında

### Benim katkım

1. **Oyun modülleri** — öğrenme refleksini güçlendiren etkileşimli oyun yüzeyleri
2. **Analiz ekranları** — ebeveynin “ne kadar gelişti?” sorusuna veriye dayalı cevap veren UI
3. **Drive JSON kayıt sistemi** — sunucusuz kalıcılık katmanı

### Mimari karar: serverless Drive

Klasik “mobil istemci + kendi API + veritabanı” yolunu bilerek seçmedik:

| Klasik backend | Qid yaklaşımı |
| --- | --- |
| Merkezî DB, işletme maliyeti | Kullanıcı Drive kotası |
| Veri stüdyoda durur | Veri aile hesabında kalır |
| Tam dosya yazımı büyüdükçe pahalı | Haftalık parçalar + satır güncellemesi |

Pratikte:

- İlerleme / analiz çıktıları **JSON** olarak Drive’a yazılır
- Dosyalar **haftalık parçalara** bölünür — tek dosyanın şişmesi engellenir
- Güncellemede mümkün olduğunca **satır seviyesinde** yazılır; gereksiz tam dosya rewrite’ından kaçınılır
- Sonuç: stüdyo tarafında barındırılan çocuk ilerlemesi yok → gizlilik ve operasyonel sadelik

### Öğrendiklerim

“Backend yok” demek mimarisizlik değil. Drive’ı bir **append/chunk depolama** gibi modellemek; kota, tutarlılık ve UI’yi aynı problemde tutmak gerekiyor. Qid’de asıl mühendislik iddiası ekran süslemek değil, **veriyi istemcide tutup yine de analiz ürünü çıkarabilmek**.
